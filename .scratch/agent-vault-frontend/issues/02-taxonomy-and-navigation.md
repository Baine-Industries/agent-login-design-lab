# Agent Vault taxonomy and navigation

Type: grilling
Status: resolved
Blocked by: none

## Question

How should Personal/Business scope, default service categories, custom categories, search, and site/account records fit into the first vault navigation so a person and an agent can both find the right Vault Item?

## Answer

- `Personal` and `Business` are Vault Space types, not separate vaults and not only filters.
- Users can create multiple named Personal Vault Spaces for family members and multiple named Business Vault Spaces for businesses or LLCs.
- Each Vault Space owns its own Core Info and Vault Items. Core Info should be visibly reusable and should auto-populate matching fields, while item-level overrides remain available.
- The navigation provides an all-spaces view with cross-space search and a selected-space switcher. Results can be grouped or filtered by service, person, or business.
- Categories are searchable labels rather than a permanent deep navigation tree. Default seeds cover common Personal and Business services; Business includes ERP. Custom categories are available from the start.
- Multiple accounts at one service remain separate Vault Items, with optional grouping by service.
